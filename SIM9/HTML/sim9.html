Ajuda — SIM9

Como usar

  1. Importe um arquivo .txt ou cole sua lista no campo "Lista cadastral".
  2. Formatos aceitos (uma linha por registro):
    • ID;TEXTO — separador ponto-e-vírgula
    • ID TEXTO — ID numérico separado por espaço (sem ponto-e-vírgula)
  3. Selecione o nivel de acuracidade desejado.
  4. Clique em Processar.
  5. Os resultados aparecem no painel direito. Clique em uma linha para ver os detalhes.
  6. No popup de detalhes, clique nos similares para marca-los como Reservados.
  7. Use os botoes de exportacao para salvar os resultados.

Niveis de Acuracidade

  • 1 — Basico: similaridade quase absoluta. Ideal para inscricoes e cadastros simples.
  • 2 — Profissional: similaridade proxima. Para cadastros corporativos sensiveis.
  • 3 — Auditoria: similaridade remota. Para codigos, emails, auditorias.
  • 4 — Premium: integracao total. Para analistas e data mining.

Formato do resultado

001 ; 002 [85%] ; 003 [62%]

A primeira coluna e o registro de referencia. Os demais sao os similares encontrados com a respectiva forca de similaridade.

Padrao de pesquisa

Filtra a analise para registros cujo texto contem o padrao informado. Util para analisar um subconjunto especifico da lista.

Reservados

Ao clicar em um similar no popup de detalhes, o registro e marcado como Reservado. Use o botao Reservados para ver e exportar essa selecao.
