SIM9 — Similaridade Textual

1. Qual o formato de entrada da lista?

Cada linha deve seguir o padrao ID;TEXTO, por exemplo: 001;Maria da Silva. O separador padrao e ponto-e-virgula (;), mas voce pode definir outro padrao no campo Padrao de separador. Se a linha nao tiver separador, o proprio texto e usado como ID.

2. Quais tipos de dado o SIM9 suporta?

A ferramenta oferece modos especializados para Nome (pessoal ou empresarial), CPF, CNPJ, Endereco e Texto livre. Cada modo aplica normalizacoes diferentes antes de comparar os registros.

3. O que sao os 4 niveis de acuracia?

Os niveis controlam a combinacao de algoritmos usados:

  • Nivel 1 (Rapido) — Levenshtein simples. Bom para listas grandes onde a velocidade importa.
  • Nivel 2 (Padrao) — Levenshtein + Soundex-BR (fonetica). Recomendado para a maioria dos casos.
  • Nivel 3 (Alto) — Adiciona Metaphone-BR. Melhor cobertura de erros foneticos.
  • Nivel 4 (Maximo) — Jaro-Winkler + todos os anteriores. O mais preciso, porem mais lento.

4. O processamento trava ou demora muito. O que fazer?

O SIM9 calcula todos os pares de registros (N × (N-1) / 2). Para listas com mais de 2 000 itens, o tempo aumenta significativamente. Use Nivel 1 para agilizar ou divida a lista em blocos menores. Listas muito grandes podem usar o modo Preview (Nivel 2+) para ver uma amostra antes do processamento completo.

5. O que e a Busca Pontual?

Permite consultar um unico texto contra toda a lista ja processada sem precisar reprocessar o lote. E util para verificar se um novo registro tem similares na base. O campo fica visivel no painel direito apos o processamento.

6. Como interpretar o Painel Analitico?

Apos processar, o painel exibe automaticamente: taxa de duplicidade, score medio, mediana, desvio padrao, faixas de concentracao (50-69%, 70-89%, 90-100%) e o registro mais duplicado. Use essas metricas para decidir se o limiar de similaridade esta adequado para seu conjunto de dados.

7. Quais formatos de exportacao estao disponiveis?

TXT (lista legivel), CSV (para importar em Excel ou banco de dados), XLSX (planilha com abas Resumo e Pares) e Relatorio (TXT completo com bloco de Resumo Analitico).

JSON Tools Pro

1. O que cada operacao faz?

  • Normalizar — Remove acentos, padroniza espacos e converte todos os valores para texto simples (string). Execute antes das demais operacoes.
  • Indentar — Formata o JSON com indentacao de 2 espacos para leitura humana.
  • Template — Gera um esqueleto do JSON com todos os campos vazios, util para criar modelos.
  • Tipos — Mostra o tipo inferido de cada campo (<string>, <number>, <boolean>).
  • JSON para CSV — Converte um array de objetos em CSV com cabecalho automatico.
  • CSV para JSON — Converte CSV (com cabecalho) em array de objetos JSON.
  • Mesclar (A+B) — Combina dois objetos JSON (Paineis 1 e 2) com mesclagem profunda (deep merge).
  • Flatten — Transforma estruturas aninhadas em chaves compostas por pontos: endereco.cidade.
  • Unflatten — Operacao inversa do Flatten: reconstroi a estrutura aninhada a partir de chaves compostas.
  • Schema — Gera um JSON Schema basico descrevendo a estrutura do objeto.

2. Por que o aviso sobre Normalizar?

A operacao Normalizar converte numeros, booleanos e nulos em texto (string). Se voce precisar preservar tipos, execute as demais operacoes primeiro e use Normalizar somente se necessario para remover acentos ou caracteres especiais.

3. Como compartilhar o resultado?

Use os botoes Email ou WhatsApp no cabecalho do Painel 3. O conteudo do resultado sera anexado automaticamente a mensagem. Para resultados muito grandes, o texto e truncado para caber no limite do canal.

4. O resultado nao aparece no Painel 3. O que fazer?

Verifique o Painel 4 (Mensagens) para ver a mensagem de erro. Causas comuns: JSON invalido no Painel 1, CSV sem cabecalho, ou Painel 2 vazio para operacoes que requerem dois paineis (Mesclar).

Baixar Imagens Automaticamente

1. Qual URL devo colar?

Acesse bing.com/images, faca sua pesquisa e copie a URL completa da barra de endereco do navegador. A URL deve conter o parametro q= com o termo de busca.

2. Posso filtrar por resolucao ou tipo de arquivo?

Sim. Preencha os campos Resolucao minima (largura x altura em pixels) e Tipos permitidos (ex: jpg,png,webp) para filtrar os resultados antes de baixar. Deixe em branco para aceitar todos.

3. As imagens sao baixadas diretamente para meu computador?

Sim. Na versao online, as imagens selecionadas sao empacotadas em um arquivo ZIP e baixadas pelo navegador. Nao e necessario instalar nada.

4. O Google nao esta funcionando como motor de busca. Por que?

O motor Google (Selenium) requer o programa desktop instalado no Windows. No modo online, use o Bing como motor de busca.
