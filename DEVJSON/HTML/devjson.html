❓ Ajuda — JSON Tools Pro

Paineis

  • 1 - Entrada A — JSON ou CSV principal. As operações usam este painel como fonte.
  • 2 - Entrada B — Segundo texto. Usado somente por Mesclar (A+B).
  • 3 - Resultado — Saída gerada. Pode ser copiada, enviada por Email/WhatsApp ou transferida para o Painel 1.
  • 4 - Mensagens — Log de operações e erros. Consulte aqui se o resultado não aparecer.

Operações

OperaçãoO que faz
NormalizarRemove acentos, padroniza espaços. Converte todos os valores para string.
IndentarFormata o JSON com recuo de 2 espaços para leitura humana.
TemplateGera esqueleto com campos vazios — útil para criar modelos de preenchimento.
TiposSubstitui cada valor pelo seu tipo inferido: <string>, <number>, <boolean>.
JSON para CSVConverte array de objetos em CSV com cabeçalho automático.
CSV para JSONConverte CSV (linha 1 = cabeçalho) em array de objetos JSON.
Mesclar (A+B)Deep merge dos Paineis 1 e 2. Chaves do B sobrescrevem as do A em conflito.
FlattenPlanifica estruturas aninhadas em chaves compostas: endereco.cidade.
UnflattenReconstrói estrutura aninhada a partir de chaves compostas por pontos.
SchemaGera JSON Schema básico descrevendo tipos e estrutura do objeto.
[!] Normalizar converte todos os valores para texto simples (string). Execute antes das demais operações e ajuste os tipos manualmente se necessário.

Compartilhamento

Use os botões Email e WhatsApp no cabeçalho do Painel 3 para enviar o resultado. Conteúdos muito grandes são truncados automaticamente para caber no limite do canal (Email: 12 000 chars, WhatsApp: 3 500 chars).
